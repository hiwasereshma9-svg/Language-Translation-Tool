# Language Translation Tool

A beginner-friendly Python web app that translates text between selected languages.

## Run locally

1. Install Python.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the app:

   ```bash
   streamlit run app.py
   ```

## Features

- Choose source and target languages
- Translate typed text
- Simple, mobile-friendly interface
- Basic error handling

## Note

The app requires an internet connection because translations are requested from an online translation service. Review important translations before relying on them.
